R2: owned tiled int8 tensor-core kernel for the packed IQ3_S / IQ3_XXS layout at any row count
(op lcpp_mul_mat_iq3_packed, csrc/lcpp_owned_iq3_mma.cu namespace tiled), replacing the unpack +
vendored MMQ path above 32 rows. Branch opt-r2 from opt-r1 (3b47510). Same microbench conventions
as R1 / K2 (GPU time per call incl. q8_1 quantize; 10 calls per CUDA graph; bf16 X; real GGUF
blocks; 350 W 3090), plus the output in X's dtype written by the kernel (MMQ: + a cast kernel).
Floors: DRAM = torch.sum over the weight bytes (same timing); int8 = 2 * rows * K * n / 284 TOPS.

Design (iterations 0-2; iteration 3 changes the tile set, the plan and the pipeline step):
  CTA = 8 warps (WM x WN), warp = 32 weight rows (two packed 16-row tiles) x 8 NT columns; tiles
  256 x 16 / 32 / 64 (8 x 1 warps) and 128 x 128 (4 x 2), the width with the fewest computed
  columns per n. A: R1's per-lane loads straight into registers one weight block ahead and R1's
  table decode (pdecode / pslice), no A tile in shared memory. B: MMQ's block_q8_1_mmq (D4)
  copied by cp.async per 128 values, 3 stages. Scaling: MMQ's per-slice term float(C) * dA * dB
  (dA = load_tiles' x_df), as fma(fma(M + C, dA, -M dA), dB, acc): the mma adds C to M = 1.5 x 2^23
  so M + C is exact, the inner fma rounds C * dA once (= I2F + FMUL). Schedule: persistent CTAs
  (1 per SM); whole tiles in waves, the last tiles % G split in K over all CTAs (stream-K), pieces
  summed in CTA (= K) order by a fixup kernel; whole tiles written in X's dtype.
